This is a code repository for the manuscript “Estimating 1a0 and 4a1 in a Life Table: A Model Approach Based on Newly Collected Data”, *Demography* (2024) 61 (3): 643–664. https://doi.org/10.1215/00703370-11330227

The MATLAB file .m produces all figures and tables included in the manuscript, using one input data file: (also within this repository). The m-file runs automatically from top to bottom, but the user may need to adjust the file paths for reading the data and saving the outputs.
